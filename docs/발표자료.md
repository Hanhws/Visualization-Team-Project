## 🎛 발표 슬라이드 조작법

- **← → / 스페이스** : 이동 (모바일은 스와이프)
- **F** : 전체화면
- **N** : 발표자 노트(각 슬라이드 대사·큐)
- **숫자키 1~9** : 해당 슬라이드로 점프

## 🗂 슬라이드 구성 (16장)

1. 타이틀 — 너에게 없는 넷플, 너플
2. 훅 — OTT 쓰시죠? (참여 유도)
3. 공감 — 볼 게 없다 + 다중구독 부담
4. 문제 — 나라마다 다른 넷플릭스 *(평가기준 1)*
5. **광고 영상 자리** (완성본 나오면 삽입 예정)
6. 솔루션 정의 + 대표 숫자
7. 데이터 파이프라인 *(평가기준 2)*
8. 차트 ① 장르 쏠림 (드라마·코미디) *(평가기준 3)*
9. 차트 ② 연도 추이·등급 *(평가기준 3)*
10. **숨은 명작 실물 — 한국 넷플에 없는 명작들** 🆕 *(잡스)*
11. 인터랙티비티 — 라이브 데모 *(평가기준 4)*
12. 기능 전체 *(평가기준 6)*
13. 배포 — Vercel *(평가기준 5)*
14. AI 활용 *(평가기준 7)*
15. 비즈니스 모델 — 로드맵
16. 클로징 + **접속 QR**
